- `install.sh`: orchestrator. Verifies network, runs reflector, formats and mounts partitions, clears `/mnt/boot`, runs pacstrap (idempotent via `pacstrap.done`), seeds pacman cache if available, writes fstab/hostname/locale/timezone/keymap, configures swap (zram/swapfile), composes mkinitcpio fragments + HOOKS and rebuilds initramfs, installs bootloader (`install-systemd-boot.sh` or `install-uki.sh`), tweaks shells/sudoers/bashrc, provisions users from `passwords/`, tunes pacman, installs yay-bin with a `paru` alias (`install-paru.sh`), installs pacman hooks, runs post-bootstrap package/service setup (`install-paru-packages-systemd.sh`), and schedules post-boot tasks (`install-post-install-setup.sh`).
- `install-post-install-setup.sh`: copies helper scripts into target (`/usr/local/sbin`) and assets into `/usr/local/share/topoos-assets`, installs/enables first-boot services (`march-post-install-config.service`, `march-post-install-packages.service`).
- `post-install-config.sh`: runs at first boot; applies firewall defaults, Samba tweaks, Sunshine setup, branding (os-release, boot entries, Plymouth theme, SDDM background, Plasma wallpaper via autostart, icon branding), fastfetch config, and system icon cache updates.
- `post-install-packages.sh`: runs at first boot; installs late packages and Flatpaks (system/user) after network is up.
- `install-paru.sh`: installs `yay-bin` in the target as the main user (temporary passwordless sudo), then symlinks `/usr/bin/paru` to `/usr/bin/yay` for compatibility.
- `install-paru-packages-systemd.sh`: from outside the chroot, installs pre-pacman/pacman/AUR packages via `yay` inside the target, then enables a set of services/timers conditionally (timesyncd, sshd, systemd-boot-update, resolved/NetworkManager DNS, ufw, bluetooth, sddm, pipewire stack, oomd, fwupd, autorotate, bolt, fstrim, man/plocate, reflector, paccache).
